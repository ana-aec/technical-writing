Exporting Generative Spatial Designs into Autodesk Revit

Category: Workflow Documentation • 4 min read

This technical guide details coordinate transformation rules and programmatic conduit asset placement when exporting from our cloud engine into desktop BIM installations.

1. Coordinate Alignment Settings

Before launching the native conversion wizard, verify your orientation matches your master grid layout specification rules:

  • Confirm system origin coordinates map to absolute world scale.
  • Set parametric angle offsets to match structural geometry bounds.

2. Running the System Script

Open your command line interface and execute the compilation routine:

npm run export -- --target=revit3d --compress=true
